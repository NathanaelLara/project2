================================================================================
                        PROBLEMAS COMUNES
================================================================================

"npm: command not found"
└─ Instala Node.js desde https://nodejs.org

"El formulario no envía"
├─ Verifica la URL en script.js
├─ Verifica que Apps Script esté publicado
└─ Revisa la consola del navegador (F12)

"No recibo emails"
├─ Verifica el email en google-apps-script.js línea 52
├─ Revisa tu carpeta de spam
└─ Verifica que los datos lleguen al Sheet

"Los estilos no se ven"
├─ Ejecuta npm run build de nuevo
├─ Limpia cache del navegador (Ctrl+Shift+R)
└─ Verifica que subiste todos los archivos de /dist

"Error al instalar dependencias"
├─ Verifica tu versión de Node.js (debe ser 18+)
├─ Borra node_modules y package-lock.json
└─ Ejecuta npm install de nuevo
